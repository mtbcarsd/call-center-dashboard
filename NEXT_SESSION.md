## Текущий статус (коротко)

Полная картина — в README.md → «Статус деплоя» и «Куда развиваться». Тут только то,
что нужно держать в голове перед тем как начинать новую задачу:

- **✅ Подробная документация (Jupyter Book) — ПОЛНОСТЬЮ ГОТОВА (2026-07-28,
  сессии J1-J8).** `docs/` — архитектура, пайплайн анализа, БД, REST API,
  Dash-дашборд (все страницы/компоненты/8 паттернов разработки), деплой,
  тестирование, история решений. Собрать локально: `pip install -r
  requirements-docs.txt && cd docs && jupyter-book build --html` (пока без
  хостинга). При следующих изменениях в проекте — обновлять соответствующий
  раздел `docs/` по месту, не откладывать (см. `JUPYTER_BOOK_DOCS_PLAN.md`).
- **✅ Миграция на Dash (D1-D5) — ПОЛНОСТЬЮ ЗАВЕРШЕНА (2026-07-22 — 2026-07-24).**
  `dash-director` — **основной публичный дашборд**:
  **https://dash-director-production.up.railway.app**. Полный паритет со
  Streamlit-версией + больше: ролевой доступ (executive/manager/employee),
  личный кабинет сотрудника с LLM-коучингом, вкладка «Звонки» с плеером/
  инлайн-редакторами/тегами/комментариями. Детальный план и статус по фазам —
  [DASH_MIGRATION_PLAN.md](DASH_MIGRATION_PLAN.md).
  - Учётки: `julia` (executive, все отделы), `boss_oo`/`boss_orkki` (manager,
    свой отдел), `sokolova` (employee, личный кабинет) — пароли в
    `scripts/seed_users.py`.
  - **Мягкий cutover, не полное отключение**: Streamlit
    (`call-center-dashboard-production-6a6b.up.railway.app`) оставлен жить как
    страховка на откат, срок отключения не назначен.
  - Кастомного домена в проекте нет — оба сервиса на `*.up.railway.app`.
- **✅ Пост-миграционная доработка (2026-07-24 — 2026-07-27) — вне исходного
  плана D1-D5, без отдельного планового документа:**
  - 2026-07-24: светлая/тёмная тема (CSS custom properties + clientside
    callback + localStorage, anti-FOUC), редизайн под единую типографику
    (Georgia serif заголовки / sans UI / mono данные), новая страница
    «Справка» (тур по страницам + честное сравнение с конкурентом, видна всем
    ролям), чекбокс «только звонки с аудио» на «Звонках», пояснение в Резюме
    для метрик-only синтетики без транскрипта.
  - 2026-07-26 — **Фаза E (Аналитика)**, по мотивам
    geckoboard.com/dashboard-examples: тренды по дням (7-дневное скользящее
    среднее для оценки/% решено/объёма) с фильтром периода (7/30/90/всё
    время) и сравнением к предыдущему периоду (`delta_badge.py`); hero-KPI
    (2 главные метрики крупным планом); лидерборд топ-3/анти-топ-3 оператора
    прямо на главном экране; проактивные алерты без LLM (пороговые эвристики
    поверх agg-периодов); автообновление раз в 90 сек без сброса диапазона
    дат.
  - 2026-07-26 — **Фаза F (Операторы)**, по мотивам
    `dash-manufacture-spc-dashboard` (Shewhart control chart): плоский
    ag-grid заменён на построчный список со спарклайном тренда оценки и
    шкалой «% ниже порога»; клик по оператору раскрывает control chart
    (норма команды = среднее ±1.5σ) с закрашенной полосой нормы; донат
    «% звонков с низкой оценкой по операторам»; quick-stats шапка
    (кол-во операторов, средняя оценка, «обновлено HH:MM»); выбор
    drill-down вынесен в `dcc.Store`, чтобы Interval не сбрасывал состояние.
  - 2026-07-27 — **Фаза G (Compliance)**, по мотивам
    `dash-clinical-analytics`: annotated heatmap «Нарушения по дням» (дни
    недели × недели периода — часовая гранулярность размазала бы 57
    нарушений почти до нуля), клик по ячейке фильтрует таблицу нарушений;
    multi-select по типу нарушения + `DatePickerRange`; технический баг
    Plotly.js (оси съезжали в "date" вместо "category" после клика) пойман и
    исправлен через explicit `type="category"` + промежуточный `dcc.Store`.
  - 2026-07-27 — drill-in по имени оператора: ссылки из таблиц «По
    операторам» на страницах «Рейтинг»/Compliance теперь ведут на
    `/operators?op=<имя>` и сразу открывают тот же control chart, что и клик
    на самой странице «Операторы» (потребовало `layout(**_query_params)` —
    `dash.page_container` передаёт query-параметры URL в `layout()`).
  - «Справка» обновлена вслед за E/F, чтобы не расходиться с реальностью
    (лидерборд, тренды/алерты, спарклайны/control chart уже не «нет» в
    сравнении с конкурентом).
  - **122 юнит-теста, 1 skip** (было 118 на момент завершения D1-D5).
