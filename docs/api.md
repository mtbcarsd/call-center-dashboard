# REST API

`api/main.py` — FastAPI-приложение, третий фасад поверх общего слоя (см.
[Архитектура](architecture.md#three-facades)). При старте (`@app.on_event
("startup")`) один раз загружается `Transcriber` (`WHISPER_MODEL`/
`WHISPER_LANGUAGE` из окружения) — не на каждый запрос.

## `GET /health`

```json
{"status": "ok", "transcriber_loaded": true}
```

## `POST /analyze` — анализ одного звонка

Принимает **либо** файл, **либо** URL — оба как поля одной
`multipart/form-data` формы:

```
file: <аудиофайл>          # опционально
url: "https://..."         # опционально, если file не передан
```

`file`/`url` — не альтернативные `Content-Type` на одном эндпоинте: FastAPI
не умеет смешивать JSON-body и `File` в одной ручке, поэтому оба поля живут
в одной форме и хотя бы одно обязательно (иначе `400`). Аудио сохраняется во
временный файл, транскрибируется, диаризуется и анализируется тем же
`orchestrator.analyze()`, что использует `pipeline.py`.

Ответ:

```json
{
  "transcript": [
    {"speaker": "Оператор", "start": 0.0, "end": 2.3, "text": "Добрый день, банк..."},
    {"speaker": "Клиент", "start": 2.5, "end": 5.1, "text": "Здравствуйте, хочу..."}
  ],
  "classification": {"topic": "кредиты", "priority": "medium"},
  "quality_score": {"total": 85, "checklist": {"greeting": true, "...": "..."}},
  "compliance": {"passed": true, "issues": []},
  "summary": "Клиент интересовался условиями кредита наличными...",
  "action_items": ["Отправить клиенту расчёт по кредиту"]
}
```

`speaker` в ответе — уже человекочитаемая метка (`Оператор`/`Клиент`/
`Неизвестно`), не сырой `operator`/`client`/`unknown` из `asr/diarizer.py`.

## `GET /trends?limit=20` — паттерны по нескольким звонкам

Бонусный эндпоинт: берёт последние `limit` звонков из `call_analysis`
(`call_topic`, `call_summary`, `key_topics`, сортировка по `analyzed_at`) и
прогоняет через `agents/trends.py`. Используется страницей «Тренды»
Dash-дашборда.

```json
{
  "trends": ["Клиенты часто уточняют условия досрочного погашения"],
  "recommendations": ["Добавить пункт про досрочное погашение в скрипт разговора"]
}
```

## `GET /coaching/{operator_name}` — рекомендации для оператора

В отличие от `/trends`, агрегацию делает сам эндпоинт (не
`agents/coaching.py`): выбирает все звонки оператора, считает среднюю оценку,
среднюю удовлетворённость клиента, долю `resolved`, проценты прохождения по
каждому пункту чек-листа (`checklist.checklist_pass_rates()`) и список
уникальных compliance-нарушений — и только потом передаёт готовую сводку
`agents.coaching.analyze_coaching()`. Если у оператора нет ни одного звонка —
возвращает пустые списки без обращения к LLM. Используется страницей «Мой
кабинет» (роль `employee`).

## `WS /transcribe/stream` — realtime-транскрибация (бонус)

Реализован, в UI дашборда пока не используется (см.
[История проекта](history.md)). Клиент шлёт WAV-чанки ~2-3 секунды бинарными
WebSocket-сообщениями, сервер транскрибирует каждый чанк независимо — **без
склейки контекста между чанками**, осознанный компромисс ради задержки
< 3 секунд. Для точного результата по всему файлу — `POST /analyze`, не этот
эндпоинт.
